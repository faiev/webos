# Third-party components

WebOS combines independently licensed open-source projects. Their licenses remain applicable to the relevant components.

| Component | Purpose | License / source |
| --- | --- | --- |
| Linux kernel | Operating-system kernel | GPL-2.0; https://kernel.org/ |
| Buildroot | Cross-toolchain, kernel, and root-filesystem build system | GPL-2.0-or-later; https://buildroot.org/ |
| BusyBox | Minimal Linux userspace utilities and shell | GPL-2.0; https://busybox.net/ |
| v86 | Browser-based x86 PC emulator and x86-to-WebAssembly JIT | BSD-2-Clause; https://github.com/copy/v86 |

The deployment workflow fetches v86 at the exact commit recorded in the workflow and copies its upstream license into the deployed site. Buildroot's legal-info output is also retained with the build artifact where available.

The WebOS repository must not remove or replace the copyright and license notices belonging to these projects. Check the exact package license manifests generated by Buildroot when redistributing a build.
