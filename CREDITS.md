# Third-party components

WebOS combines independently licensed open-source projects. Their licenses remain applicable to the relevant components.

| Component | Purpose | License / source |
| --- | --- | --- |
| Linux kernel | 64-bit x86-64 operating-system kernel | GPL-2.0; https://kernel.org/ |
| Buildroot | Cross-toolchain, kernel, and root-filesystem build system | GPL-2.0-or-later; https://buildroot.org/ |
| BusyBox | Minimal Linux userspace utilities and shell | GPL-2.0; https://busybox.net/ |
| v64 | Browser-based x86/x86-64 PC emulator and x86-to-WebAssembly JIT | BSD-2-Clause; https://github.com/speedyHKjournalist/v64 |

The deployment workflow copies v64's upstream license into the deployed site and runs Buildroot's legal-info target. The resulting Buildroot license texts and package manifests are published under the Pages site's licenses/buildroot/ directory. Keep these notices with any redistributed Linux image.

v64 is derived from v86 and retains the v86 contributor copyright and license terms. The WebOS build keeps the complete license file with the emulator assets.

The WebOS repository must not remove or replace the copyright and license notices belonging to these projects. Check the exact package license manifests generated by Buildroot when redistributing a build.
